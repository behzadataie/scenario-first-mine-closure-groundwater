# Contributing

Open an issue before proposing changes to scenario definitions, forecast calculations, observation weights, or published analysis tables. Pull requests should include:

- a concise scientific rationale;
- tests or validation output;
- updated documentation and data dictionary;
- regenerated figures where outputs change;
- no credentials, private data, manuscript-review files, or personal absolute paths;
- no large binary model workspaces in ordinary Git.

External MODFLOW 6 and PESTPP-IES executables must not be committed to this repository.
