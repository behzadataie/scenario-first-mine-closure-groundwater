# Release notes

## v1.0.0 - public reproducibility release candidate

- provides deterministic MODFLOW 6 and continuous-K / pilot-point PESTPP-IES source code;
- provides compact final parameter and simulated-observation ensembles for the four retained scenarios;
- provides processed deterministic-screening, threshold-sensitivity, Wilson-interval, bootstrap, parameter-forecast, and observation-forecast tables;
- provides editable SVG figure masters and scripts for regenerating data-driven figures;
- documents the scenario-conditioned scope of the stochastic experiment and its distinction from common-data multi-model analysis;
- excludes manuscript drafts, peer-review files, credentials, personal paths, licensed executables, large transient workspaces, and raw MODFLOW binaries;
- includes release validation, checksums, tests, a security policy, and GitHub-Zenodo publication guidance.
