## Suggested description

This software release provides source code, compact final PESTPP-IES parameter and simulated-observation ensembles, processed analysis tables, and editable figures for a synthetic scenario-first mine-closure groundwater uncertainty benchmark. The workflow formalizes deterministic screening of evidence-consistent conceptual hypotheses before within-scenario stochastic refinement. The completed stochastic runs are scenario-conditioned synthetic experiments and do not assign probabilities to conceptual scenarios. MODFLOW 6 and PESTPP-IES executables are not redistributed.
